RC Deploy API:
- POST /deploy/rolling — triggers rolling deploy, returns { status, message }
- GET /deploy/status — returns deploy progress { status, pods: [{ pod_id, status }], ... }
- POST /deploy/{pod_id} — deploy to single pod

RC Exec API:
- POST /pods/{id}/exec — body: { command: string }, returns { stdout, stderr, exit_code }
