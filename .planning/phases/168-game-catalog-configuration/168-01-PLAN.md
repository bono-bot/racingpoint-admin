# Plan 168-01: Game Catalog & Active Games

## Objective

Add game management capabilities: game catalog display, launch/stop games on pods, and active games overview.

## Tasks

### Task 1: Add game management API functions

**File:** `src/lib/api/games.ts`

Add to existing gamesApi:

```typescript
getGamesCatalog: () => rcFetch('/games/catalog') as Promise<{ games: GameCatalogEntry[] }>,
launchGame: (data: { pod_id: string; sim_type: string; driver_id: string; session_id?: string }) =>
  rcFetch('/games/launch', { method: 'POST', body: JSON.stringify(data) }),
stopGame: (podId: string) =>
  rcFetch('/games/stop', { method: 'POST', body: JSON.stringify({ pod_id: podId }) }),
getActiveGames: () => rcFetch('/games/active') as Promise<ActiveGame[]>,
```

Add interfaces:
```typescript
interface GameCatalogEntry {
  id: string; // SimType enum value
  name: string;
  abbr: string;
  installed_pod_count: number;
}

interface ActiveGame {
  pod_id: string;
  pod_number: number;
  sim_type: string;
  driver_id: string;
  driver_name: string;
  started_at: string;
}
```

Re-export from index.ts.

**Commit:** `feat(168-01): add game catalog, launch, stop, and active games API functions`

### Task 2: Create games management page

**File:** `src/app/(dashboard)/games/page.tsx` (NEW)

Page with two sections:

**Game Catalog** (top):
- Grid of game cards from `gamesApi.getGamesCatalog()`
- Each card: game name, abbreviation, icon (colored circle with abbr), installed on X/8 pods
- Color coding per game type (AC=red, F1=blue, iRacing=yellow, LMU=green, Forza=purple)

**Active Games** (bottom):
- Table from `gamesApi.getActiveGames()` with SWR polling (5s)
- Columns: Pod #, Game, Driver, Started (time ago), Actions
- Stop button per row → calls `gamesApi.stopGame(podId)` with confirmation
- "Launch Game" button → modal:
  - Pod dropdown (from fleet health, only idle pods)
  - Game dropdown (from catalog)
  - Driver dropdown (from driversApi.getDrivers())
  - Launch button → calls `gamesApi.launchGame()`

**Commit:** `feat(168-01): create games management page with catalog and active games`
