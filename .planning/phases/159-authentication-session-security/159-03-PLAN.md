1. Create `src/components/AuthProvider.tsx`:
- 'use client' directive
- Export interface AuthUser { sub: string; role: string; exp: number; iat: number }
- Export interface AuthContextValue { user: AuthUser | null; isAuthenticated: boolean; isAdmin: boolean; logout: () => Promise&lt;void&gt; }
- Export const AuthContext = createContext&lt;AuthContextValue&gt;({ user: null, isAuthenticated: false, isAdmin: false, logout: async () => {} })
- Export function AuthProvider({ children }):
  - State: user (AuthUser | null), starts null
  - useEffect on mount: fetch('/api/auth/me'), if ok parse JSON and setUser(data) if data.sub exists
  - logout callback: POST to '/api/auth/logout', setUser(null), router.push('/login')
  - Compute isAdmin: user?.sub === 'admin' &amp;&amp; user?.role === 'staff'
  - Render AuthContext.Provider with value { user, isAuthenticated: !!user, isAdmin, logout }

2. Create `src/hooks/useAuth.ts`:
- 'use client' directive
- Import useContext from react, AuthContext from @/components/AuthProvider
- Export function useAuth(): AuthContextValue { return useContext(AuthContext) }

3. Create `src/hooks/useSessionExpiry.ts`:
- 'use client' directive
- Import useEffect, useRef from react; useAuth from @/hooks/useAuth; useToast from @/components/Toast
- Export function useSessionExpiry():
  - Get { user, logout } from useAuth() and { toast } from useToast()
  - warnedRef = useRef(false)
  - useEffect (deps: [user?.exp, logout, toast]):
    - If !user?.exp, return
    - check function: compute remaining = user.exp - Math.floor(Date.now() / 1000)
      - If remaining <= 0: call logout()
      - Else if remaining <= 300 and !warnedRef.current: set warnedRef.current = true, call toast('Session expiring in 5 minutes. Save your work.', 'info')
    - Set interval every 30000ms (30 seconds) calling check
    - Call check() immediately
    - Return cleanup that clears interval

- DashboardLayout renders: AuthProvider > SessionExpiryWatcher > AdminLayout > {children}
