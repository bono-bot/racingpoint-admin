# Plan 167-01: Enhanced Bookings & Tournament Management

## Objective

Enhance the bookings page with source filtering and detail view, and enhance the tournaments page with registration lists and improved match management.

## Tasks

### Task 1: Enhance bookings page

**File:** `src/app/(dashboard)/bookings/page.tsx`

Read the existing page first. Add:
- Source filter tabs: All | WhatsApp | Discord (filter on `booking.source`)
- Status filter: All | Confirmed | Cancelled
- Date range picker (date_from, date_to params)
- Clickable rows that expand to show booking detail inline:
  - Full customer info (name, phone, email)
  - Booking type, session date, time range
  - Calendar event ID (if linked)
  - Cancel button (calls `eventsApi.cancelBooking(id)`) with confirmation
- Summary stats at top: total bookings, confirmed count, WhatsApp vs Discord split

**Commit:** `feat(167-01): enhance bookings with source filter, date range, and detail view`

### Task 2: Enhance tournaments page

**File:** `src/app/(dashboard)/tournaments/page.tsx`

Read the existing page first. Add:
- Tournament detail view when clicking a tournament:
  - Registration list (from `eventsApi.getTournamentRegistrations(id)`)
  - Bracket visualization (matches grouped by round)
  - Match result recording: click a match → select winner → call `eventsApi.recordMatchResult()`
- Create tournament form improvements:
  - Track/car selection (text fields)
  - Format selection (single elimination, round robin)
  - Max participants
- Tournament status badges: upcoming, in_progress, completed

**Commit:** `feat(167-01): enhance tournaments with registrations, bracket view, and match results`

### Task 3: Add time trials section

**File:** `src/app/(dashboard)/leaderboard/page.tsx`

Read the existing page first. Add a "Time Trials" tab alongside the leaderboard:
- List active time trials from `eventsApi.getTimeTrials()`
- Create time trial button → modal (track, car, duration fields)
- Time trial card: track, car, participants count, best time

**Commit:** `feat(167-01): add time trials tab to leaderboard page`
