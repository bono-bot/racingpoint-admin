# Plan 169-01: Control Room Overview

## Objective

Transform the dashboard overview page into a real-time mission control view showing fleet status, active sessions, system health, and quick actions in one glance.

## Tasks

### Task 1: Rewrite overview page as control room

**File:** `src/app/(dashboard)/page.tsx`

Replace the current basic stats page with a mission control layout:

**Row 1: Key Metrics** (4 cards)
- Active Sessions (count from `billingApi.getActive()`) — red accent
- Fleet Online (count from `fleetApi.getHealth()` where ws_connected=true) — emerald accent
- Today's Revenue (sum from active sessions pricing) — blue accent
- System Health (aggregate from `/api/health`) — amber/emerald based on status

**Row 2: Fleet Overview** (left 60%) + Active Sessions (right 40%)
- Fleet: Mini pod grid (8 pods as small status circles — green=idle, red=error, blue=in_session, grey=offline). Click → /fleet
- Active Sessions: Compact list of running sessions (pod#, driver, game, elapsed time). Click → /billing

**Row 3: Quick Actions** (left) + System Status (right)
- Quick Actions: Grid of icon buttons — Start Session, Wake All Pods, View Fleet, Billing History, Games, AI Chat
- System Status: Dynamic health checks (not hardcoded):
  - Fetch `/api/health` for admin app status
  - Fetch fleet health for pod count
  - Show RC status from fleet health response
  - Gateway from existing health check
  - Use real data, not hardcoded "connected" strings

**SWR polling:** 10s refresh for fleet + sessions, 30s for health.

All sections link to their respective detail pages.

**Commit:** `feat(169-01): rewrite dashboard as real-time control room with fleet, sessions, and health`
