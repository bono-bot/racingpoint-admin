# Plan 166-01: Wallet Log Enhancement & Membership Members

## Objective

Enhance the wallet-transactions page with per-driver filtering and the memberships page with an active members list.

## Tasks

### Task 1: Enhance wallet-transactions page with driver filter

**File:** `src/app/(dashboard)/wallet-transactions/page.tsx`

Read the existing page first. Add:
- Driver dropdown/search filter at the top (fetch driver list from `driversApi.getDrivers()`)
- When a driver is selected, show their wallet balance prominently
- Filter transactions by driver_id query param
- Keep existing date picker, summary cards, payment method breakdown
- Add a "Top Up" button when a driver is selected (calls `driversApi.topupWallet`)

Use the existing page patterns and SWR where possible.

**Commit:** `feat(166-01): add driver filter and topup to wallet transactions page`

### Task 2: Enhance memberships page with active members list

**File:** `src/app/(dashboard)/memberships/page.tsx`

Read the existing page first. The "Active Members" tab currently shows a placeholder. Enhance:
- Fetch active memberships from RC: `rcFetch('/customer/membership/active')`
- Display as a table: Driver Name, Tier, Hours Used/Included, Status, Started, Expires
- Status badges: active (green), expiring soon (yellow, <7 days), expired (red)
- Progress bar for hours used vs included
- If the endpoint doesn't exist, show "No active members yet — members appear when customers subscribe via the PWA" (graceful fallback)

**Commit:** `feat(166-01): add active members table to memberships page`
