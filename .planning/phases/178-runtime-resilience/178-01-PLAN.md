  <action>
Create two new modules:

**src/lib/api/circuit-breaker.ts:**
- Export a `CircuitState` type: `'closed' | 'open' | 'half-open'`
- Export a `CircuitBreakerOptions` interface: `{ failureThreshold: number; cooldownMs: number; onStateChange?: (state: CircuitState) => void }`
- Export a `CircuitBreaker` class:
  - Constructor takes `CircuitBreakerOptions` with defaults: `failureThreshold=3`, `cooldownMs=30000` (30s)
  - Private state: `state: CircuitState` (starts 'closed'), `failureCount: number`, `lastFailureTime: number`, `onStateChange` callback
  - `getState(): CircuitState` — public getter
  - `async call<T>(fn: () => Promise<T>): Promise<T>` — the main wrapper:
    - If state is 'open': check if cooldown has elapsed. If yes, transition to 'half-open' and allow ONE probe request. If no, throw `new Error('Circuit breaker is open')`.
    - If state is 'half-open': run fn. On success, reset to 'closed' (failureCount=0). On failure, go back to 'open' and reset timer.
    - If state is 'closed': run fn. On success, reset failureCount. On failure, increment failureCount. If failureCount >= threshold, transition to 'open' and record lastFailureTime.
    - On state transition, call `onStateChange` callback if provided.
  - `reset(): void` — force reset to closed (for testing)
- Export a singleton `circuitBreaker` instance with default options (onStateChange will be wired in Plan 02)

**src/lib/api/retry.ts:**
- Export a `RetryOptions` interface: `{ maxRetries: number; baseDelayMs: number; shouldRetry?: (error: unknown) => boolean }`
- Export `async function withRetry<T>(fn: () => Promise<T>, options?: Partial<RetryOptions>): Promise<T>`
  - Defaults: `maxRetries=3`, `baseDelayMs=1000`
  - Loop up to maxRetries. On each failure:
    - If `shouldRetry` returns false, throw immediately (for circuit breaker open errors and 4xx client errors)
    - Wait `baseDelayMs * 2^(attempt-1)` ms (1s, 2s, 4s)
    - Retry
  - After all retries exhausted, throw the last error
  - Default `shouldRetry`: return false for errors with message containing 'Circuit breaker is open' or '4' as first char of status. Return true otherwise.
  - Use `await new Promise(r => setTimeout(r, delay))` for the wait

Both files must have zero `any` types — use generics throughout.
