1. In `db/mod.rs`, add a new CREATE TABLE IF NOT EXISTS in `init_db()`:
```sql
CREATE TABLE IF NOT EXISTS deploy_logs (
    id TEXT PRIMARY KEY,
    app TEXT NOT NULL,
    timestamp TEXT NOT NULL,
    deployer TEXT NOT NULL DEFAULT 'james',
    result TEXT NOT NULL,
    pages_before INTEGER,
    pages_after INTEGER,
    pages_missing TEXT,
    duration_secs INTEGER,
    error TEXT,
    build_hash TEXT
)
```

2. In `api/routes.rs`, add two routes in `service_routes()` (no auth — deploy script on LAN):
   - `.route("/deploy-log", post(create_deploy_log))`
   - `.route("/deploy-log", get(list_deploy_logs))`

3. Add the `create_deploy_log` handler:
   - Accept JSON body with fields: `app` (string, required), `result` (string: "success"|"failed"|"rollback"), `deployer` (string, default "james"), `pages_before` (optional int), `pages_after` (optional int), `pages_missing` (optional string — comma-separated list), `duration_secs` (optional int), `error` (optional string), `build_hash` (optional string)
   - Generate UUID id and UTC ISO timestamp
   - INSERT INTO deploy_logs
   - Return 201 with `{ "id": "...", "status": "logged" }`

4. Add the `list_deploy_logs` handler:
   - SELECT * FROM deploy_logs ORDER BY timestamp DESC LIMIT 50
   - Return 200 with JSON array

5. Deserialize struct:
```rust
#[derive(Deserialize)]
struct CreateDeployLog {
    app: String,
    result: String,
    #[serde(default = "default_deployer")]

    pages_before: Option<i64>,
    pages_after: Option<i64>,
    pages_missing: Option<String>,
    duration_secs: Option<i64>,
    error: Option<String>,
    build_hash: Option<String>,
}
fn default_deployer() -> String { "james".to_string() }
```

Follow the activity_log.rs pattern: UUID id, UTC timestamp, fire-and-forget tokio::spawn for DB insert. No `.unwrap()` in production (standing rule).
