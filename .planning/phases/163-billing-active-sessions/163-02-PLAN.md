Button styling: `text-xs px-2 py-1 rounded hover:bg-{color}-400/10 transition-colors disabled:opacity-30 disabled:cursor-not-allowed` (same pattern as fleet pod action buttons).

**Idempotency:** Track `actionInProgress` state as `Record<string, string>` mapping session ID to action name. When an action is in progress for a session, disable ALL buttons for that session row. Set `actionInProgress[id] = 'pausing'` before the call, clear it after success/error.

Each action: call billingApi method -> toast.success on success -> mutate SWR -> toast.error on failure. Pattern:
```typescript
async function handleAction(id: string, actionName: string, fn: () => Promise<void>) {
  setActionInProgress(prev => ({ ...prev, [id]: actionName }));
  try {
    await fn();
    toast.success(`Session ${actionName}`);
    mutate();
  } catch (e) {
    toast.error(`Failed to ${actionName}: ${(e as Error).message}`);
  } finally {
    setActionInProgress(prev => { const n = { ...prev }; delete n[id]; return n; });
  }
}
```
