**Critical:**

  - Types: @types/better-sqlite3 7.6.13

**AI/ML:**
- tesseract.js 7.0.0 - OCR for receipt and bank statement scanning via browser
  - Detects text in images for structured data extraction

**Infrastructure:**
- next (Next.js core) - Server routing, API routes, streaming

## Configuration

**Environment:**
Environment variables (dev and production):
- `NEXT_PUBLIC_GATEWAY_URL` - Frontend-facing gateway URL (default: http://localhost:3100)
- `NEXT_PUBLIC_GATEWAY_API_KEY` - Gateway API key (default: rp-gateway-2026-secure-key)
- `GATEWAY_URL` - Server-side gateway URL (same as above)
- `GATEWAY_API_KEY` - Server-side gateway key
- `RC_URL` - RaceControl Core API endpoint (default: http://localhost:8080)
- `RACECONTROL_URL` - Alternative RaceControl URL (default: http://localhost:8080)

**Build:**
- `next.config.ts` - Next.js configuration with:
  - `output: "standalone"` - Self-contained build output
  - `serverExternalPackages: ["better-sqlite3"]` - Prevents bundling native SQLite
  - Turbopack root configuration
- `tsconfig.json` - TypeScript compiler options:
  - Target: ES2017
  - Module: esnext
  - Path alias: `@/*` → `./src/*`
  - Strict mode enabled
- `postcss.config.mjs` - PostCSS configuration with Tailwind CSS plugin
- `.eslintrc` - ESLint configuration (via eslint-config-next)

## Platform Requirements

**Development:**
- Node.js (supports recent versions)
- npm or compatible package manager
- SQLite support (handled by better-sqlite3)
- 200+ MB disk space for node_modules

**Production:**
- Node.js server environment (Vercel, self-hosted, Docker)
- File system access for `data/admin.db` SQLite database
- Network access to:
  - Gateway service (GATEWAY_URL)
  - RaceControl Core (RC_URL, RACECONTROL_URL)
  - Hiring bot (http://localhost:3050)

## Deployment

**Build Output:**
- Standalone Next.js build with production optimization
- Compressed and tree-shaken
- Server and client bundles separated

**Database:**
- SQLite at `data/admin.db` (created on first run)
- WAL mode enabled for concurrent access
- Foreign keys enabled

**Scripts:**
```bash
npm run dev    # Development server (http://localhost:3000)
npm run build  # Production build
npm run start  # Start production server
npm run lint   # Run ESLint
```
