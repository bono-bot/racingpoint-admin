# Requirements: Admin Dashboard (v20.0)

**Defined:** 2026-03-22
**Core Value:** Staff can manage pods, billing, and fleet operations from a single authenticated dashboard

## Authentication & Authorization

- [x] **AUTH-01**: Admin can log in via RaceControl /auth/admin-login with PIN
- [x] **AUTH-02**: Session persists across browser refresh via JWT in httpOnly cookie
- [x] **AUTH-03**: Unauthenticated users are redirected to login page
- [x] **AUTH-04**: RC proxy routes are protected — only authenticated requests forwarded
- [ ] **AUTH-05**: Role-based access control distinguishes admin vs staff permissions (infrastructure only — no gating implemented)
- [x] **AUTH-06**: User can log out and session is invalidated

## Shared Infrastructure

- [x] **INFRA-01**: API client split into domain modules (fleet, billing, drivers, events, games, ops)
- [x] **INFRA-02**: Toast notification system (sonner)
- [x] **INFRA-03**: Form validation with zod + react-hook-form
- [x] **INFRA-04**: Centralized icon module (lucide-react)

## Fleet Monitoring

- [x] **FLEET-01**: Real-time fleet health dashboard showing all pod statuses
- [x] **FLEET-02**: Pod health cards with version, uptime, and status indicators
- [x] **FLEET-03**: Activity log with pod filter and pagination
- [x] **FLEET-04**: SWR polling for real-time updates

## Fleet Actions & Deployment

- [x] **FLEET-05**: Pod actions: wake, shutdown, restart, lockdown
- [x] **FLEET-06**: Bulk fleet actions (wake-all, shutdown-all, restart-all)
- [x] **FLEET-07**: Confirmation dialog for dangerous actions
- [x] **FLEET-08**: Deploy section with deploy UI
- [x] **FLEET-09**: Remote exec on individual pods
- [x] **FLEET-10**: Deploy status tracking

## Billing — Active Sessions

- [x] **BILL-01**: Active billing sessions with live countdown table
- [x] **BILL-02**: Start session modal
- [x] **BILL-03**: Stop, pause, resume, extend session actions
- [x] **BILL-04**: Event timeline per session
- [x] **BILL-05**: SWR polling for real-time session updates

## Billing — Management

- [x] **BILL-06**: Session history with date/status/pod filters
- [x] **BILL-07**: Refund modal with reason input
- [x] **BILL-08**: Split billing view
- [x] **BILL-09**: Daily billing reports
- [x] **BILL-10**: Billing rate management (CRUD)
